# Design Thinking Course for Businesses — Hands-On Activities

**WSQ Course Code:** TGS-2026064719  |  **TSC:** Design Thinking Practices (DSN-ACE-3014-1.1)  |  **Version v15.0**

7 facilitated activities across 4 topics. Every activity runs in the browser — no software installation is required.

## Ed-tools used

| Ed-tool | Link | Used for |
|---|---|---|
| Design Thinking Toolkit | [alfredang.github.io/designthinking/](https://alfredang.github.io/designthinking/) | Empathy Map, Persona, Journey Map, POV, HMW, Brainstorm, Prototype and Test canvases — the primary tool for this course. |
| RACI Matrix | [alfredang.github.io/raci/](https://alfredang.github.io/raci/) | Assign Responsible / Accountable / Consulted / Informed roles so a design idea has a clear owner when it moves to delivery. |
| Scrum Planner | [alfredang.github.io/scrum/](https://alfredang.github.io/scrum/) | Turn validated design concepts into a prioritised product backlog and sprint plan. |
| Digital Transformation Canvas | [alfredang.github.io/digitaltransformation/](https://alfredang.github.io/digitaltransformation/) | Position a design initiative within the organisation's wider transformation roadmap. |
| Business Continuity Management | [alfredang.github.io/bcm/](https://alfredang.github.io/bcm/) | Stress-test a design solution for operational risk and continuity before rollout. |
